# Minecraft Protocol implementation
This is personal repository for minecraft protocol implementation (mc-protocol) written
in rust. It's not made for general use, but using and contributing to it isn't prohibited.

## Implemented features
- Configuration / join process
- Simple world generation / manipulation and saving changes in RAM (limited)
- Simple chat system (join / leave messages and syncronized chat)

## Usage
- Dev test:
  cargo run [PORT (optional)]
- Build:
  cargo build [--release (optional)]
